# حكايتنا ❤️ — هدية رقمية رومانسية تفاعلية

موقع تفاعلي من صفحة واحدة، يجمع بين تجربة عيد ميلاد رومانسية ومعرض ذكريات
وقلب تفاعلي ورسالة سرية وعداد للقصة وخط زمني ومفاجأة نهائية — كل ذلك في
تجربة قصصية متدرجة، بتصميم ليلي فخم ودعم كامل للغة العربية (RTL).

## 📁 هيكل المشروع

```
/
├── index.html          → الهيكل والأقسام
├── style.css            → كل التصميم والحركات
├── script.js             → المنطق والتفاعلات
├── config.js             → كل النصوص والصور والتواريخ (هذا هو الملف الوحيد الذي تحتاج لتعديله عادة)
├── assets/
│   ├── images/            → ضع صورك هنا (photo1.jpg, photo2.jpg ...)
│   └── music/               → ضع مقطوعة رومانسية هنا باسم romantic.mp3
└── README.md
```

## ✏️ كيف تخصص الموقع

كل ما تحتاج تعديله موجود داخل `config.js`:

- **name / yourName** — اسم من تهديه الموقع وتوقيعك أنت.
- **startDate** — تاريخ بداية القصة، يُستخدم في عداد الذكريات (بصيغة `YYYY-MM-DD`).
- **heroTitle / heroDate** — عنوان وتاريخ قسم البداية.
- **photos** — مصفوفة الصور مع تعليق نصي لكل صورة.
- **messages** — الرسائل التي تظهر واحدة تلو الأخرى.
- **secretMessage** — نص الرسالة السرية (استخدم `\n` لسطر جديد).
- **timeline** — نقاط الخط الزمني (العنوان، التاريخ، الرسالة، صورة اختيارية).
- **finalMessage / finalNote** — نصوص المفاجأة النهائية.
- **musicSrc** — مسار الموسيقى الخلفية.
- **colors** — الألوان الأساسية للموقع.

لا حاجة لفتح `style.css` أو `script.js` إلا إذا أردت تعديلات تصميم متقدمة.

## 🖼️ إضافة الصور

ضع صورك داخل `assets/images/` بنفس الأسماء المذكورة في `config.js`
(مثل `photo1.jpg`, `photo2.jpg`, ...) أو غيّر المسارات في `config.js` لتطابق
أسماء ملفاتك. يفضل أن تكون الصور مربعة أو قريبة من المربع لأفضل شكل في
معرض الصور.

## 🎵 إضافة الموسيقى

ضع ملف صوتي بصيغة `mp3` داخل `assets/music/` باسم `romantic.mp3` (أو غيّر
`musicSrc` في `config.js`). الموسيقى تشتغل تلقائيًا بمجرد الضغط على زر
"ابدئي الحكاية" في البداية (لأنها لحظة تفاعل مباشر من المستخدم)، وزر
النوتة الموسيقية أعلى الشاشة يسمح بإيقافها أو تشغيلها يدويًا.

## 🎬 إضافة فيديو المفاجأة (التورطة الثانية)

في آخر الموقع، بعد فتح صندوق الهدية، يظهر زر "التالي" ينقل إلى شاشة فيها
فقاعة كبيرة تتفرقع عند الضغط عليها ويظهر بعدها فيديو بحجم شبه كامل للشاشة
(مع هامش بسيط حول الفيديو تظهر فيه خلفية النجوم). لتفعيله:

1. ضع ملف الفيديو بصيغة `mp4` داخل `assets/video/` باسم `surprise.mp4`
   (أو غيّر `videoSurpriseSrc` في `config.js` ليطابق اسم ملفك).
2. الفيديو يشتغل تلقائيًا بالصوت لحظة الضغط على الفقاعة (لأنها لحظة تفاعل
   مباشر من المستخدم، فالمتصفح يسمح بذلك).
3. لو الملف كبير الحجم، يفضل ضغطه أولًا (مثلًا عبر HandBrake) حتى يفتح
   بسرعة على الهاتف.

## 💻 تشغيل الموقع محليًا

الموقع Static بالكامل، يمكنك فتحه مباشرة، لكن يفضل تشغيله عبر خادم محلي
بسيط حتى تعمل الصور والموسيقى بدون مشاكل متصفح:

```bash
# باستخدام بايثون
python3 -m http.server 8000

# ثم افتح المتصفح على
http://localhost:8000
```

أو ببساطة استخدم إضافة "Live Server" في VS Code.

```bash
git branch -M main
git remote add origin <رابط-المستودع-الخاص-بك>

```

## 🚀 النشر على Vercel

1. ادخل إلى https://vercel.com وسجّل الدخول (يفضل عبر GitHub).
2. اضغط **Add New → Project**.
3. اختر مستودع GitHub الذي رفعت إليه المشروع.
4. لا حاجة لأي إعدادات بناء (Build Command) — الموقع Static بالكامل، اترك
   الإعدادات الافتراضية واضغط **Deploy**.
5. بعد دقائق سيعطيك Vercel رابطًا مباشرًا للموقع جاهزًا للمشاركة.

## ✅ ملاحظات

- الموقع لا يحتاج أي Backend أو قاعدة بيانات.
- يعمل بشكل كامل على الهاتف والكمبيوتر (Responsive 100%).
- يحترم إعداد "تقليل الحركة" (Reduced Motion) في أنظمة التشغيل.
- إذا لم تجد صورة معينة، ستُخفى تلقائيًا بدون كسر التصميم — لكن يفضل
  إضافة كل الصور المذكورة في `config.js` لأفضل تجربة.
